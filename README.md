# Booth Game Proposals

A static, informational proposal page for Zoho Catalyst at React Hyderabad Utsavam 2026. No build step or dependencies are required.

## Preview locally

Open `index.html` in a web browser. Alternatively, from this directory run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Host on GitHub Pages

1. Push `index.html`, `style.css`, and this README to a GitHub repository.
2. In the repository's **Settings → Pages**, choose **Deploy from a branch**.
3. Select the branch containing the files and the `/ (root)` folder, then save. GitHub will provide the published URL on the Pages settings screen.
