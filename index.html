Proposed Technical Booth Games

Engaging technical challenges designed to introduce attendees to the Zoho ecosystem and Zoho Catalyst capabilities.

THE PROPOSALS

Two ideas for the booth.

01

GAME ONE

Memory Tiles

Flip. Remember. Match.

Concept

A memory card-matching challenge where participants match Zoho products with their corresponding use cases.

Try Memory Tiles ↗(opens in a new tab)

How it works

  • Participants see a grid of face-down tiles.
  • Each tile hides either a Zoho product or a business or technical use case.
  • Participants flip two tiles per turn.
  • A correct product-to-use-case match remains visible; incorrect pairs flip back over.
  • Participants match all pairs before the timer runs out.
  • Winners are determined by completion time and number of attempts.

Example matches

ProductUse case
Zoho CRMManage customer relationships
Zoho DeskManage customer support tickets
Zoho FlowAutomate workflows between applications
Zoho CatalystBuild and deploy cloud applications
Zoho CreatorBuild low-code business applications
Zoho AnalyticsAnalyze business data

Product awareness: Participants discover Zoho products and understand what each one is used for.

Suggested duration: 1–2 minutes

02

GAME TWO

Query Quest

Query. Discover. Unlock.

Concept

A mini database investigation challenge that simulates the use of ZCQL (Zoho Catalyst Query Language).

How it works

  • Participants receive a short mystery or data-finding challenge.
  • Participants use a sample dataset of fictional event attendees.
  • Participants use clues to write a ZCQL query that identifies the correct record.
  • They can test their queries in a simulated environment.
  • Each correct query reveals an answer or secret code.
  • Participants complete the challenge by submitting the correct result.
  • Winners are determined by accuracy and completion time.

Example challenge

Clue: Find the attendee whose city is Hyderabad and whose points are greater than 80.

Sample fictional dataset

Example query (illustrative; adapt to the actual Catalyst table and column identifiers)

SELECT Name FROM Attendees WHERE City = 'Hyderabad' AND Points > 80;

Product awareness: Participants experience a simulation of how ZCQL can be used to query application data.

Suggested duration: 3–5 minutes
